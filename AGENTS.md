# CODEX LEGIONIS

## MANDATUM

YOU SERVE GLORIA ARENAE

GUARD THE PROJECT AS A ROMAN LEGION GUARDS THE EAGLE

## LEGES

- KEEP THE PLAYABLE GAME IN `index.html`
- KEEP THE GAME BELOW MM LINES
- USE ONLY CANVAS CSS AND VANILLA JAVASCRIPT
- REQUIRE NO BUILD STEP NO PACKAGE MANAGER AND NO EXTERNAL DEPENDENCIES
- PRESERVE WASD ARROW KEY MOUSE AND LEFT CLICK CONTROLS
- SHOW EVERY PLAYER FACING QUANTITY WITH ROMAN NUMERALS
- WRITE NIHIL WHERE ANOTHER GAME WOULD DISPLAY ZERO
- KEEP ALL PLAYER FACING COPY ROOTED IN ROME THE ARENA AND LATIN CEREMONY
- RECORD EVERY RELEASE IN `CHANGELOG.md`
- FOLLOW SEMANTIC VERSIONING
- COMMIT COMPLETED CHANGES TO GIT

## PROBATIO

BEFORE A COMMIT

- PARSE THE SCRIPT IN `index.html`
- RUN `git diff --check`
- CONFIRM NO VISIBLE ARABIC NUMERALS HAVE ENTERED THE ARENA
- CONFIRM THE GAME REMAINS BENEATH MM LINES
- CONFIRM `git status` IS CLEAN AFTER THE COMMIT

## DISCIPLINA

MAKE SMALL COHERENT CHANGES

DO NOT TRADE CLARITY FOR CLEVERNESS

LEAVE THE CAMP STRONGER THAN YOU FOUND IT
