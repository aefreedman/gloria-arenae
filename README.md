# GLORIA ARENAE

> AVE GLADIATOR
>
> ENTER THE SAND EARN THE FAVOR OF THE PLEBS AND CLAIM GLORY BEFORE ROME

## IMPERIUM

GLORIA ARENAE IS A COMPLETE ARENA GAME FOR THE BROWSER

THE ENTIRE CAMPAIGN LIVES IN `index.html`

THERE IS NO BUILD STEP NO INSTALLATION AND NO TRIBUTE OWED TO EXTERNAL DEPENDENCIES

## IN ARENAM DESCENDE

OPEN `index.html` IN A MODERN BROWSER

PRESS THE INSCRIBED BUTTON AND THE GATES WILL OPEN

## CONTROLS

| ACTIO | IMPERIUM |
| --- | --- |
| MARCH | WASD OR ARROW KEYS |
| AIM THE GLADIUS | MOUSE |
| STRIKE | LEFT CLICK OR HOLD LEFT CLICK |
| MOBILE MARCH | DRAG THE LEFT THUMB |
| MOBILE AIM AND STRIKE | DRAG AND HOLD THE RIGHT THUMB |

## PROELIA

- SURVIVE V WAVES
- FACE LEGIONARIES SAGITTARII LIONS AND PRINCEPS ARENAE
- GATHER DENARII FROM FALLEN ENEMIES
- BUY FAVORS BETWEEN BATTLES
- SEND THE CHAMPION TO ORCUS

EVERY QUANTITY SEEN BY THE PLAYER USES ROMAN NUMERALS

NIHIL STANDS IN PLACE OF ZERO

## TABULAE

- `index.html` CONTAINS THE COMPLETE GAME
- `CHANGELOG.md` CONTAINS THE ANNALES OF SEMANTIC RELEASES
- `AGENTS.md` CONTAINS THE CODEX FOR FUTURE LEGIONARIES
